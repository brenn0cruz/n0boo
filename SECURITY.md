# Security policy

This public repository contains educational prototypes and synthetic demonstrations only.

## Reporting
Please avoid publishing any suspected credential or sensitive-information exposure in a public issue. Contact the repository owner through their public professional profile for a private disclosure.

## Scope
No project is connected to production networks, bank systems, clients, or employer infrastructure. All example addresses use documentation ranges, and all example identities are fictional.

## Before contributing
Do not submit tokens, passwords, API keys, private keys, real operational logs, customer records, proprietary code, internal diagrams, or environment files.
